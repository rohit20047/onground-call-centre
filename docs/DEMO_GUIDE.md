# Two-minute submission demo

## Before recording

- Confirm the deployed app and Node API are reachable and the reviewer access code is available separately.
- Confirm two verified numbers can be connected by this Exotel account, with sufficient trial credits.
- Have the agent phone and willing recipient ready. Use headphones/speaker placement that avoids feedback.
- Keep Exotel credentials, payment details, and private numbers outside the recording frame.
- Start with uncompleted sample tasks in a clean browser profile if you want to demonstrate resolution.

## Recording sequence (target 110 seconds)

1. **0-15s:** Dashboard: KPIs, progress, earnings, waiting queue, tasks, and seven-day charts.
2. **15-30s:** Open the hot-lead modal; expand a signal and page to the next lead.
3. **30-45s:** Calls to make: expand a lead and change pages. Show Incoming and Recent briefly.
4. **45-85s:** Start a real call to the approved recipient. Answer the agent phone, show the recipient phone ringing, exchange a short greeting, then hang up. Show provider status and call ID. Do not imply `in-progress` alone proves the recipient answered.
5. **85-100s:** Calendar month navigation, Pulse channel, send a message and resolve the pinned callback task.
6. **100-110s:** Show the completed call in Recent and save a manual outcome. Mention React + Node.js + Exotel, with sample business data.

If final provider duration is delayed, show it after it arrives rather than fabricating a duration. If calling fails, resolve that before claiming the assignment is finished.
